System 01

👑 ระบบลำดับชั้นสังคม

ระบบหลักที่ทำให้เกมแตกต่าง — ผู้เล่นไต่จากชาวนาธรรมดาสู่กษัตริย์ผู้ปกครองอาณาจักร กษัตริย์สามารถถูกโค่นล้มได้!

🏗️ ลำดับชั้น 7 ระดับ

👑
กษัตริย์ (King)
ปกครองอาณาจักรทั้งหมด | ตั้งภาษี, ประกาศสงคราม, ออกกฎหมาย
1 คน / Kingdom
🏛️
ขุนนาง (Duke / Lord)
ดูแลเมืองย่อย | เก็บภาษีเมือง, จ้างทหาร, สร้างปราสาท
3-5 คน
⚔️
อัศวิน (Knight)
ผู้บัญชาการกองทัพ | ใช้ม้าศึก, อาวุธ Tier 3+, นำทัพ
10 คน
🛡️
ทหาร (Soldier)
ปกป้องอาณาจักร | เข้าค่ายทหาร, อาวุธ Tier 2, รับเงินเดือน
ไม่จำกัด
🔨
ช่างฝีมือ (Artisan)
ผู้เชี่ยวชาญคราฟ | เปิดร้าน, คราฟของ Tier สูง
ไม่จำกัด
🌾
ชาวนา (Peasant)
จุดเริ่มต้น | ทำนา, ตัดไม้, ขุดแร่, ทำงานจ้างพื้นฐาน
เริ่มต้น
⛓️
นักโทษ (Prisoner)
สถานะลงโทษ | จำกัดทุกอย่าง, ต้องรอหมดโทษหรือหนีคุก
ลงโทษ

📜 วิธีเลื่อนชั้น

จาก → ไป วิธีการ เงื่อนไข
ชาวนา → ช่างฝีมือ เรียนรู้ Crafting Skill ถึง Lv.10 500 Gold
ชาวนา → ทหาร สมัครเข้ากองทัพ Combat Lv.5 + ผ่าน Trial
ทหาร → อัศวิน ได้รับแต่งตั้งจาก Lord / King ชนะ Tournament / Quest พิเศษ
ช่างฝีมือ/ทหาร → ขุนนาง ซื้อที่ดิน + ได้รับแต่งตั้ง 10,000 Gold + Reputation 500
ขุนนาง → กษัตริย์ ชนะการเลือกตั้ง / สงครามกลางเมือง / สืบราชบัลลังก์ ต้องเป็น Duke ก่อน
⚠️ ระบบโค่นล้มกษัตริย์
กษัตริย์สามารถถูกโค่นล้มได้! ถ้า Approval Rating ต่ำกว่า 20% จะเกิด Event "การปฏิวัติ" ที่ผู้เล่นทุกคนสามารถโหวตให้โค่นกษัตริย์ได้ — ภาษีสูงเกินไป = เสี่ยงหลุดจากบัลลังก์!

System 02

💰 ระบบเศรษฐกิจ

Player-driven economy ที่สมจริง — ผู้เล่นเป็นคนกำหนดราคาสินค้าเอง พร้อมระบบภาษีที่ส่งผลต่อการเมือง

🪙 สกุลเงิน 3 ระดับ

🟤 Copper (ทองแดง)
⚪ Silver = 100 Copper
🟡 Gold = 100 Silver

🏪 ระบบตลาด

🏬
NPC Shops
ขายของพื้นฐาน ราคาตายตัว — เป็น Floor Price ป้องกัน Inflation ในเกม
🛒
Player Market
ผู้เล่นตั้งร้านขายของเอง กำหนดราคาเอง — Economy ขับเคลื่อนโดยผู้เล่น
🔨
Auction House
ประมูลของหายาก อาวุธ Legendary ม้าหายาก — แข่งเสนอราคากัน
🕶️
Black Market
ซื้อ-ขายของผิดกฎหมาย (ยาพิษ, ของขโมย) — ถ้าโดนจับ จะถูกขังคุก!

🏛️ ขุนนางเมือง
ภาษี 10-20% →

System 03

⚔️ ระบบต่อสู้

Combat ที่สนุกและ Skill-based — ไม่ใช่แค่คลิกรัวๆ มี Parry, Combo, Dodge และท่าพิเศษตามอาชีพ

🗡️ ประเภทอาวุธ

ประเภทตัวอย่างลักษณะเหมาะกับ
🗡️ ดาบ (Sword)ดาบสั้น, ดาบยาว, Claymoreบาลานซ์ ความเร็ว + ดาเมจทั่วไป
🪓 ขวาน (Axe)ขวานมือเดียว, Battle Axeดาเมจสูง, ช้าTank
🔱 หอก (Spear)หอก, Halberdระยะไกล, ป้องกันม้าทหาร
🏹 ธนู (Bow)ธนูสั้น, Longbow, Crossbowระยะไกลนักยิง
🛡️ โล่ (Shield)โล่ไม้, โล่เหล็กป้องกัน, ParryTank
🔮 เวทมนตร์ (Magic)ไม้เท้า, หนังสือเวทAoE, SupportMage

🎯 Combat Mechanics

LMB Light Attack เร็ว, ดาเมจน้อย — ใช้สร้าง Combo
Hold LMB Heavy Attack ช้า, ดาเมจมาก — ทำลาย Block
F Block / Parry กดจังหวะถูก = Parry → ศัตรูเปิดช่อง
2x Dir Dodge / Roll หลบ i-frame สั้นๆ — Double tap ทิศทาง
Q Special Ability ท่าพิเศษตามอาชีพ — มี Cooldown
L+L+H Combo Attack Light → Light → Heavy = Combo พิเศษ

System 04

📖 ระบบเควส

เควสที่ไม่ได้มีแค่ "ไปฆ่า 10 ตัว" — มี Story 4 Act และ Choice ที่ส่งผลต่อเกม

⚔️ Main Quest — เส้นทางสู่บัลลังก์

Act 1: จุดเริ่มต้น Lv.1-10
1. ตื่นขึ้นมาในหมู่บ้าน → เรียนรู้ระบบพื้นฐาน (เดิน, ต่อสู้, คราฟ)
2. ช่วยหมู่บ้านจากโจรกลุ่มแรก → ได้อาวุธแรก
3. พบนักรบปริศนา → เปิดเผยว่าคุณมีสิทธิ์ในบัลลังก์
4. เลือก: เชื่อเขา หรือ ไม่เชื่อ → เปลี่ยน Quest Path
Act 2: เส้นทางแห่งอำนาจ Lv.10-30
1. เลือกเส้นทาง: ทหาร / ช่างฝีมือ / นักเวท → Quest Chain แตกต่าง
2. ฝึกฝนอาชีพที่เลือก → ปลดล็อค Skill ใหม่
3. ค้นพบภัยคุกคามต่ออาณาจักร — กลุ่มลับกำลังวางแผนยึดอำนาจ
4. สร้างพันธมิตรกับ NPC หรือ ผู้เล่นคนอื่น
Act 3: มหาสงคราม Lv.30-50
1. รวบรวมพันธมิตร → เลือกฝ่ายในสงครามกลางเมือง
2. ยึดป้อมปราการ → Siege Quest (ผู้เล่นหลายคนร่วมรบ)
3. เผชิญหน้ากับ Final Boss ของ Act → Demon General
4. ผลลัพธ์: เปลี่ยนผู้นำ Kingdom ตามฝ่ายที่ชนะ
Act 4: ราชาผู้ครองบัลลังก์ Lv.50+
1. ขึ้นครองราชย์ หรือ สนับสนุนผู้นำคนอื่น
2. ปกครองอาณาจักร → Kingdom Management Quest
3. ภัยคุกคามใหม่จากต่างแดน — ต้องรวมผู้เล่นทั้ง Server
4. Endgame: สร้าง Legacy → ชื่อของคุณถูกจารึกในเกม

ไม่ใช่แค่สร้างบ้าน — สร้างเมือง สร้างอาณาจักร! ระบบที่ดิน + อาคาร 10+ ประเภท

อาคารต้นทุนฟังก์ชัน
🏠 บ้านไม้100 Goldที่พักพื้นฐาน, เก็บของ 20 ช่อง
🏡 บ้านหิน500 Goldที่พักอัพเกรด, เก็บของ 50 ช่อง

⚒️ โรงตีเหล็ก1,200 Goldคราฟอาวุธ/เกราะ Tier 2+
🎪 ค่ายทหาร2,000 Goldฝึกทหาร NPC, เก็บอาวุธ
🧱 กำแพงเมือง3,000 Goldป้องกันเมืองจากการบุก
⛪ มหาวิหาร5,000 GoldHeal, Buff, Revive ราคาถูก

🗼 หอสังเกตการณ์1,500 Goldเห็นแผนที่กว้างขึ้น, เตือนศัตรู

Summary

🔄 Core Game Loop

วงจรการเล่นเกมหลักที่ทำให้ผู้เล่นกลับมาเล่นซ้ำ — ตั้งแต่ระยะสั้นไปจนถึงระยะยาว

🔄 Main Game Loop
🌅 เข้าเกม
→
📋 รับ Daily Quest
→
❓ เลือกกิจกรรม
⚔️ Combat / PvP
🌾 ฟาร์ม / คราฟ
🤝 ค้าขาย / การเมือง
💰 ได้ XP + เงิน + ของ
→
📈 Level Up / เลื่อนชั้น
→
👑 ไต่สู่กษัตริย์!

🎯 Engagement Loops

⚡ Short-term 5-15 นาที
  • ทำ Daily Quest → ได้รางวัลทันที
  • PvP Duel → ได้เงิน/เสียเงิน
  • คราฟของ → ขายใน Market
  • ฟาร์มพืช → เก็บเกี่ยว → ขาย
🔥 Mid-term 1-3 ชั่วโมง
  • ลง Dungeon → หาของหายาก
  • Tournament → แข่งชิงแชมป์
  • Trade Route → ซื้อถูกขายแพงข้ามเมือง
  • Siege War → ร่วมรบยึดป้อม
👑 Long-term หลายวัน
  • เลื่อนลำดับชั้น → จากชาวนาเป็นกษัตริย์
  • สร้าง Kingdom → รวมพล + สงคราม
  • Clan War → ยึดดินแดน
  • Legacy → ชื่อจารึกในเกม
Roadmap

🗓️ Roadmap การพัฒนา

แผนพัฒนาเกม 4 เฟส รวม 16 สัปดาห์ — จาก MVP สู่ Launch

Phase 1

🏗️ MVP — แกนหลักของเกม

สัปดาห์ที่ 1-4
  • Map พื้นฐาน (Capital City + 2 เมืองย่อย + ป่า + เหมือง)
  • ระบบ Combat พื้นฐาน (ดาบ + ธนู + Block)
  • ระบบ Social Hierarchy (ชาวนา → ทหาร → อัศวิน)
  • ระบบเศรษฐกิจพื้นฐาน (NPC Shop + เงิน)
  • ระบบฟาร์ม + ขุดแร่
  • Daily Quest พื้นฐาน
  • DataStore (Save ข้อมูลผู้เล่น)
Phase 2

📦 Content Expansion — เนื้อหาเพิ่ม

สัปดาห์ที่ 5-8
  • ระบบคราฟ + Mini-Game
  • ระบบ Kingdom Building
  • เพิ่มอาวุธ + เกราะ Tier 2-3
  • Tournament + PvP Arena
  • Monster + Dungeon (2 แห่ง)
  • ระบบ Guild/Clan
Phase 3

🤝 Social & Politics — สังคมและการเมือง

สัปดาห์ที่ 9-12
  • ระบบเลือกตั้ง + กฎหมาย
  • ระบบ Reputation
  • ระบบ Alliance + สงคราม
  • เพิ่ม Event ต่างๆ (Tournament, Siege, Dragon Raid)
  • Player Market + Auction House
Phase 4

🚀 Polish & Launch — ขัดเงาและเปิดตัว

สัปดาห์ที่ 13-16
  • ระบบ Monetization (Gamepass + Dev Products)
  • UI/UX Polish — ปรับ Interface ให้สวยงาม
  • Bug Fixing + Balancing
  • Beta Test กับกลุ่มผู้เล่น
  • Launch + Marketing 🎉
